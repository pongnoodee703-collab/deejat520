# DeejatBakery — เกมทำขนมร้านขนมปัง (ชื่อเดิม N&J restaurant)

## รุ่นที่ 16.1: หน้าทำขนมเสร็จ + ป๊อปอัพทั้งหมด เป็นร้านเบเกอรี่โทนน้ำตาลอ่อน สไตล์ทันสมัย (ล่าสุด)
- **หน้าสรุปผล (ทำขนมเสร็จ ทั้ง 3 ด่าน)** (`css/ui.css`): เดิมพื้นเหลือง-ชมพู การ์ดขอบชมพู → หน้าร้านเบเกอรี่:
  กันสาดลายทางคาราเมล-ครีมขอบหยัก, ผนังไม้ระแนงสีลาเต้ + ไฟอุ่นตรงกลาง, บัวผนัง, เคาน์เตอร์ไม้อ่อนมีขนมอบวางโชว์ ;
  การ์ดผลลัพธ์ครีมขอบคาราเมล แถบลายบนหัว เงานุ่ม, ชื่อขนมมีเส้นประใต้, ปุ่ม "ทำอีกครั้ง" คาราเมล / "เลือกเมนูอื่น" ครีม ;
  แถบสถานะมือถือเป็นสีบิสกิตเข้ากับหน้า
  - วาดด้วย CSS ล้วน (พื้นหลังหลายชั้น + ::before/::after) ไม่มีรูป ไม่มี DOM เพิ่ม ไม่มีแอนิเมชันวนเพิ่ม → เบาเครื่อง
- **ป๊อปอัพทุกอัน** (ตั้งค่า / สูตร / วิธีเล่น / แพ้): ครีมขอบคาราเมล แถบลายกันสาดบนหัวเหมือนกันหมด + เงานุ่มแบบสมัยใหม่ ;
  ป้าย "ผ่านด่านฝึกแล้ว" เป็นสีครีม-คาราเมล
- **ปุ่มพื้นฐานทั้งเกม**: ปุ่มหลักเป็นคาราเมล, ปุ่มรองเป็นครีมขอบบิสกิต (เดิมชมพู/เขียวมิ้นต์)
- **แก้บั๊ก**: ปุ่ม "🔁 ทำอีกครั้ง / 🍰 เลือกเมนูอื่น" หน้าสรุปผลตกเป็น 2 บรรทัดบนมือถือ → บรรทัดเดียวแล้ว
- ทดสอบ: หน้าสรุปผล 3 ด่าน × ไทย/อังกฤษ ปุ่มบรรทัดเดียว การ์ดอยู่ในจอครบ (390×844, 320×568, แนวนอน 844×390) ;
  ป๊อปอัพแพ้แสดงครบในจอ ; เล่นจบครบ 3 ด่าน ได้ 3 ดาว ไม่มี error ทั้งไฟล์แยกและไฟล์เดียว

## รุ่นที่ 15.9: ฉากใส่วัตถุดิบ (โยนของลงหม้อ/ชาม) ใช้ง่ายขึ้น ไม่ลายตา ธีมเบเกอรี่
- **สายพานวัตถุดิบเดินทีละช่องแล้วหยุดพัก** (`js/pests.js` → `Conveyor`) แทนการไหลตลอดเวลา:
  หยุดทีไรการ์ดเรียงพอดีกลางชั้น **เห็นเต็มใบ ไม่โดนขอบตัด** → อ่านชื่อ/แตะง่าย ; แตะชั้น = หยุดใต้นิ้วทันที ;
  ลาก/ปัดเองแล้วปล่อย = เข้าช่องพอดีเอง ; ล้อเมาส์ 1 จังหวะ = 1 ช่อง
  - ลูกเล่นด่านยังอยู่: ด่าน 1 เดินช้าทางเดียว / ด่าน 2 กลับทิศ 🔄 / ด่าน 3 เดินถี่ขึ้นช่วงสั้น ๆ ⚡ ; ด่านฝึกไม่เดินเอง
  - **ขั้นใส่วัตถุดิบไม่มีของกระโดดเองแล้ว** (เดิมการ์ดกระโดดเป็นคลื่นจนแตะพลาด) — แตะที่ว่างบนสายพานยังกระโดดเล่นได้ ;
    ตู้โชว์ขนม (ขั้นที่ไม่ต้องหยิบของ) ยังกระโดดดึ๋งเบา ๆ
- **โยนของลงหม้อ/ชามให้เห็นชัด** (`js/cookfx.js` → `CookFx.toss`): แตะการ์ด → วัตถุดิบลอยเป็นวงโค้งนุ่ม ๆ จากการ์ด
  (หรือจากจุดที่ปล่อยนิ้วถ้าลากมา) ไปเหนือภาชนะ แล้วต่อด้วยท่าเท/ตอกไข่/โรย/ตกตุ๋มตรงจุดเดียวกันพอดี ไม่กระตุก ;
  แตะรัว ๆ = ลอยไปทีละชิ้นห่างกันนิดนึง ไม่พุ่งพร้อมกัน ; ระดับในภาชนะนับถูกเสมอ และไปถึงค่าสุดท้ายก่อนเริ่มขั้นถัดไป
- **การ์ดที่ใส่แล้วมี ✓ สีเขียว** ชัด ๆ (เดิมแค่จางหาย) ; ของผิดยังเป็น ✕ สีแดง ; ไฮไลต์ตัวที่ถูกเรืองนุ่ม ๆ ช้าลง (ไม่กระพริบรัว)
- **ลดสิ่งที่ลายตา**: ของบนการ์ดไม่ส่ายดุ๊กดิ๊กแล้ว, ของไม่เด้งตอนสายพานวิ่ง, เพื่อนชูนิ้ว 👍 โดยไม่มีของปลิวออกข้าง (ของที่ลงหม้อจริง
  มีแค่ตอนเพื่อนลงมือช่วย), ชั้นขนมบนผนังโยกเบาลง/ช้าลง, ขนมปังในตู้ด้านหลังที่โผล่ใต้หม้อ/ชามถูกซ่อน (เหลือเฉพาะสองข้างฉาก
  และแถวขนมปังพอดีความกว้างจอ ไม่ล้นข้างเดียว)
- แก้บั๊ก: สายพานรอบเก่าที่ยังค้างอยู่ (กรณีเฟรมถูกหน่วง) จบเองทันทีเมื่อเปลี่ยนขั้น — ไม่เกิด error ตอนเปลี่ยนขั้นเร็ว ๆ
- ทดสอบ: การ์ดหยุดพักตรงช่องทุกครั้ง, ด่าน 2 กลับทิศจริง, แตะ/ลากใส่ของแล้วของลอยลงภาชนะ, แตะรัว 3 ชิ้นระดับถูก (0.42 ตรงสูตร),
  ✓ ขึ้นบนการ์ดที่ใส่แล้ว, ไม่มีอะไรทับกันทุกขั้น, เล่นจบครบ 3 ด่าน (ด่าน 1 แบบสอนเล่น) ทั้งไฟล์แยก/ไฟล์เดียว ได้ 3 ดาว ไม่มี error

## รุ่นที่ 15.8: ดาวปกติ (ไม่หมุน) + แก้บั๊กหน้าเลือกเมนู/หน้าสรุปผล
- **ดาวเป็นดาวปกติ อยู่นิ่ง**: ดาวความยากบนการ์ดเมนูไม่ส่าย/หมุนแล้ว, แตะดาวไม่หมุน 360° แล้ว (`js/screens.js`, `css/menu.css`),
  ดาวหน้าสรุปผลขึ้นมาเฉย ๆ ไม่หมุนเข้ามา (`css/ui.css`) — ดาวที่ลอยขึ้นตอนทำแต่ละขั้นเสร็จยังอยู่ (ไม่หมุน)
- **แก้บั๊ก**
  - เปลี่ยนความยากในตั้งค่าขณะอยู่หน้าเลือกเมนู → ป้าย "🎯 ความยาก: ..." บนหัวยังเป็นค่าเก่า → ตอนนี้เปลี่ยนตามทันที (การ์ดอัปเดตด้วย)
  - เปลี่ยนเชฟในตั้งค่าขณะอยู่หน้าสรุปผล → รูปเชฟบนหน้าสรุปผลยังเป็นตัวเก่า → ตอนนี้เปลี่ยนตาม
  - แตะปุ่มความยากระดับเดิมซ้ำ ไม่บันทึก/วาดหน้าใหม่โดยเปล่าประโยชน์
- **ตรวจทุกไฟล์**: CSS ทุกไฟล์วงเล็บครบ, JS ทุกไฟล์โหลดได้ไม่มี error, ข้อความทุกคีย์มีครบทั้งไทย/อังกฤษ, สูตรไทย-อังกฤษตรงกันทุกขั้น ;
  เล่นจบครบ 3 ด่าน (ด่าน 1 แบบสอนเล่นเต็มรูปแบบ) ทั้งไฟล์แยกและไฟล์เดียว ได้ 3 ดาว ไม่มี error

## รุ่นที่ 15.7: ชั้นวางขนมกลับมาบนผนังทุกด่าน + ฉากทำอาหารพอดีไม่ทับกัน + ตั้งค่าเหลือแต่ที่จำเป็น
- **ชั้นวางขนมกลับมาบนผนังครัวเหมือนเดิม ทุกด่าน** (`js/wallshelf.js`): ปัดซ้าย-ขวาเลื่อนวนรอบ, ปัดแรงไหลต่อ, ลากของขึ้นมาขยับเล่น
  (ปล่อยบนชั้น = ย้ายช่อง), แตะของ = เด้ง, แตะที่ว่าง = ทั้งชั้นกระโดด — เพิ่มขนมปังอบบนชั้น (🥐🍞 / 🍩🥖 / 🥨🥯) รวม 7 ชิ้น ต้องปัดดู
  - รุ่น 15.6 ย้ายชั้นไปเล็ก ๆ บนเคาน์เตอร์ และ **บนมือถือหลายขนาด (เช่น 360×640) ชั้นถูกซ่อนหายไปเลย** → แก้แล้ว

  3. จอเตี้ย → ชั้นขึ้นไปแทนที่กันสาด (ฉากเล็กลงน้อยกว่า) ; 4. จอเล็กมาก → บนเคาน์เตอร์ระหว่างเพื่อน ; ซ่อนเฉพาะจอเล็กจนฉากจะเล็กเกินเล่น

  - ขนาดฉากคงที่ทุกขั้นในด่าน (แก้ฉากยืด-หด 1px ระหว่างขั้นจากการปัดเศษความสูงแผงล่าง)

## รุ่นที่ 15.3: ชั้นวางกระโดดได้ — สายพานวัตถุดิบ + ชั้นนม-ไข่-พุดดิ้ง
- **สายพานวัตถุดิบกระโดดได้** (ทุกด่าน): **แตะที่ว่างบนสายพาน = ของทั้งแถวกระโดดเป็นคลื่น** จากซ้ายไปขวา แล้วตกกลับลงสายพาน
  (ไม่นับเป็นการใส่ของ ไม่เปลี่ยนขั้น ; ของที่กำลังลอยยังแตะใส่ชามได้) — ครั้งแรกของเมนู เพื่อนบอก "แตะสายพาน = กระโดด!"
- **ลูกเล่นสายพานเพิ่มการกระโดด**: ด่าน 1 ของกระโดดดึ๋ง ๆ เบา ๆ เป็นระยะ / ด่าน 2 กลับทิศ สลับกับกระโดด /
  ด่าน 3 เร่งความเร็ว สลับกับกระโดดสูง (ป้าย "🦘 ของบนสายพานกระโดด!") — ด่านฝึกไม่มีลูกเล่น
- **ชั้นนม-ไข่-พุดดิ้งบนผนังกระโดดได้**: แตะที่ว่างบนชั้น = ทั้งชั้นกระโดดเป็นคลื่น (ย่อตัว → ลอย → ยุบ → เด้ง) ;
  ตอนสายพานกระโดด ชั้นบนผนังก็กระโดดตาม ; แตะของ = เด้งสูงขึ้นกว่าเดิม (เลื่อน/หยิบ/ย้ายช่องได้เหมือนเดิม)
- ชั้นทั้งสองตัดภาพแค่ซ้าย-ขวา (ของวนรอบลอดขอบ) ข้างบนเปิดให้กระโดดพ้นชั้นได้ ; การกระโดดคำนวณในรอบวาดเดิม ไม่มีลูปเพิ่ม
- กฎแพ้จากรุ่น 15.2 ยังอยู่ครบ: ปัดของแปลกปลอมไม่ทัน = แพ้ "ขนมปนเปื้อน!" / ขนมไหม้ = แพ้ → เริ่มเมนูใหม่
- **ทดสอบอัตโนมัติ 151 รายการ ผ่านทั้งหมด ไม่มี error** (เพิ่ม 11: แตะสายพาน = กระโดดแล้วตกกลับ, ไม่กระทบการทำขนม,
  ลูกเล่นกระโดดทั้ง 3 ด่าน, ชั้นบนผนังกระโดดเป็นคลื่นแล้วนิ่ง, ไม่มีลูปค้างหลังออกจากครัว)

  - **ปัด/ลากซ้าย-ขวา = เลื่อนชั้น** ของวิ่งวนพ้นขอบแล้วโผล่อีกด้าน, ปัดแรงแล้วปล่อย = ไหลต่อแล้วค่อย ๆ หยุด, ของเอนตามแรง, ล้อเมาส์ก็เลื่อนได้
  - **ลากของขึ้น/ลงออกจากชั้น = หยิบมาขยับเล่นได้ทั่วจอ** — ปล่อยเหนือชั้น = ย้ายไปวางช่องนั้น (ของข้าง ๆ เลื่อนหลบนุ่ม ๆ),
    ปล่อยที่อื่น = ลอยกลับที่เดิมแล้วเด้ง (ไม่กระทบการทำขนม ไม่นับเป็นการใส่ของ)
  - **แตะของ = เด้งดึ๋ง** + ลูกเล่นเล็ก ๆ (ไข่ → 🐣, นม → 💧, น้ำผึ้ง → 🐝, พุดดิ้ง → 💛 ...) ; ของบนชั้นโยกเบา ๆ ตลอด
  - เดิมชั้นนี้ซ่อนบนมือถือ → ตอนนี้ **แสดงบนมือถือด้วย** (ซ้ายบนใต้หัวใจ เห็นทีละ 4 ชิ้น ชิ้นที่ 5 ต้องเลื่อนดู) ;
    แท็บเล็ต/แนวนอนเห็นครบ 5 ชิ้น ; กระดานชอล์กย้ายไปขวาใต้หน้าต่างบนมือถือ (จอเตี้ยมากซ่อนกระดาน)
  - อยู่เหนือพื้นที่ทำอาหาร จึงแตะได้จริง แต่อยู่ใต้ชั้นของแปลกปลอม (แตะปัดของที่หล่นได้เสมอ)
  - **ลื่น**: มีลูป rAF เฉพาะตอนลาก/ไหล/ลอยกลับ ตอนนิ่งไม่มีลูปเลย ; ขยับด้วย translate/transform อย่างเดียว ; โหมดเบาปิดการโยก
- **ทดสอบอัตโนมัติ 139 รายการ ผ่านทั้งหมด ไม่มี error** (เพิ่ม 17: ชั้นแสดงครบ 5 ชิ้นและแตะได้จริงทั้ง 3 ด่าน, ลากเลื่อนตามนิ้ว,
  ลูปหยุดเองตอนนิ่ง, ของวนอยู่ในรอบ, หยิบแล้วปล่อยที่หม้อ = ลอยกลับ ไม่กระทบขั้นทำขนม, ปล่อยบนชั้น = ย้ายช่อง, แตะ = เด้ง, ออกจากครัวแล้วสะอาด)

## รุ่นที่ 15: ไม่ปัดของแปลกปลอม = แพ้ + เพื่อนลงมือช่วยทำขนมจริง + ครัวเบเกอรี่เต็มขึ้น + ปลอดภัย/ลื่นขึ้น
- **ของแปลกปลอมตกใส่ขนม = แพ้ทันที** (`Pests.land` → `G.fail('dirty')`) หน้าแพ้ "ขนมปนเปื้อน! 🤢" → เริ่มเมนูใหม่
  - ให้ยุติธรรม: **วงเตือนสีแดงตรงจุดที่จะตก** ค่อย ๆ ใหญ่/ชัดขึ้นจนถึงตอนตก, เสียงเตือน "ติ๊ด-ตื๊อ" ตอนเริ่มหล่น,
    เพื่อนฝั่งที่ของหล่นตะโกน "ระวัง!", แตะหรือกวาดนิ้วผ่านก็ปัดได้ (พื้นที่แตะ 64px) ; โหมดง่าย/ด่านฝึก เพื่อนช่วยปัดให้บ้าง
  - **ด่านฝึก (ด่านแรกครั้งแรก): ชิ้นแรกหยุดกลางอากาศ** วงเหลืองกระพริบ + มือ 👆 + เชฟบอก "แตะเพื่อปัดทิ้ง (ถ้าตกใส่ขนม = แพ้)"
    รอจนผู้เล่นแตะ แล้วชม "เก่งมาก!" ; ในด่านฝึกตกใส่ขนมก็ไม่แพ้ แค่บอก
  - ปิดได้ที่ ⚙️ → 🦟 ของแปลกปลอมหล่นมา (ปิดกลางเกม = ของที่หล่นอยู่จางหาย เพื่อนยังช่วยทำขนมต่อ)
- **เพื่อน ๆ ลงมือช่วยทำขนมจริงทุกด่าน** (`G.assist` ในแต่ละกลไก + `Helpers.lend`):
  ทุก ๆ 5–11 วินาที (ตามความยาก) เพื่อนโยนของที่ถืออยู่เป็นวงโค้งลงหม้อ/ชาม แล้ว **ความคืบหน้าขยับจริง** —
  ช่วยคน +12% / ช่วยร่อน 1 ครั้ง / ช่วยแต่งหน้า-เทถ้วย 1 ชิ้น (สูงสุด 3 ครั้งต่อขั้น และไม่ทำแทนจนจบ ขั้นสุดท้ายให้ผู้เล่นทำเอง) ;
  ขั้นหยิบของ = ชี้ของที่ถูกบนสายพาน (ยาก/ปิดไฮไลต์ = ไม่ชี้) ; ขั้นเตาอบ = กระโดดตะโกน "กดเลย!" ตอนเข็มเขียว
- **ครัวในเกมเป็นร้านเบเกอรี่เต็มขึ้น**: **ตู้กระจกโชว์ขนมปัง** บนเคาน์เตอร์ด้านหลัง (ครัวซองต์ บาแก็ต ขนมปัง เพรตเซล โดนัท พาย)
  + **กระดานชอล์ก "เมนูวันนี้"** ราคาทั้ง 3 เมนู ขีดเส้นใต้เมนูที่กำลังทำ (ภาพนิ่ง วาดครั้งเดียว ; จอเตี้ยมากซ่อนกระดาน)
- **สายพานมีลูกเล่นเพิ่ม**: ปัดแรงแล้วปล่อย = สายพานไหลต่อแล้วค่อย ๆ หยุด, ของเอนตามความเร็ว (เร่ง = เอนมาก),
  ของเด้งเบา ๆ เหมือนกลิ้งผ่านลูกกลิ้ง (ลูกเล่นเดิมยังอยู่: ด่าน 2 กลับทิศ / ด่าน 3 เร่งเป็นช่วง ๆ / ลากเลื่อน / ล้อเมาส์)
- **ลื่นขึ้น**: สายพานไม่ค้นหาหน้าเว็บทุกเฟรม (เช็กสถานะ 5 ครั้ง/วินาที) และวัดขนาดใหม่เฉพาะตอนชั้นเปลี่ยนขนาด (ResizeObserver),
  กวาดนิ้วปัดของคำนวณตำแหน่งจากเวลาแอนิเมชัน (ไม่อ่านเลย์เอาต์ระหว่างลาก), ท่าทางเพื่อนเริ่มใหม่ด้วย 2 เฟรมแทนการบังคับคำนวณเลย์เอาต์
- **ปลอดภัยขึ้น**: ไฟล์เกมไฟล์เดียวมี Content-Security-Policy เข้มงวด (ห้ามเชื่อมต่อเน็ต/ส่งฟอร์ม/โหลดสคริปต์ภายนอก) + no-referrer ;
  คะแนนดาวที่เก็บในเครื่องรับเฉพาะเมนูที่มีจริงและเลข 1–3 ; `build.py` ไม่ยอมฝังไฟล์นอกโฟลเดอร์โปรเจกต์ แจ้งชัดถ้าไฟล์หาย และกัน `</style`/`<!--` ที่ทำไฟล์เดียวพัง
- แก้บั๊ก: ด่านฝึกลองใหม่ได้เฉพาะไหม้/ไม่สุก (เดิมแพ้ชนิดอื่นจะหาข้อความไม่เจอ), ปิดด่านฝึกกลางคันตอนของหยุดกลางอากาศ → หล่นต่อปกติ,
  ปิดของแปลกปลอมกลางเกมไม่หยุดเพื่อนช่วยทำขนม ; ป้ายตั้งค่าสั้นลงไม่ดันสวิตช์ตกบรรทัด ; ท้ายหน้าตั้งค่าแสดงเลขรุ่น
- **ทดสอบอัตโนมัติ 122 รายการ ผ่านทั้งหมด ไม่มี error และไม่มีอะไรโดน CSP บล็อก** (เพิ่ม: ไม่ปัด = แพ้ + เริ่มใหม่ได้, วงเตือนขึ้น/หาย,
  ด่านฝึกหยุดกลางอากาศ + มือ + คำชม, เพื่อนช่วยคน/ร่อน/แต่งหน้าแล้วความคืบหน้าขยับจริง, เพื่อนชี้ของที่ถูก, ปัดสายพานแล้วไหลต่อแล้วหยุด)

## รุ่นที่ 14.1: ตรวจรอบสุดท้าย + เก็บงาน
- **วัดลูกเล่นสายพานตามเวลาจริง** (ไม่บังคับ) ทั้ง 3 ด่าน: ด่าน 1 วิ่งทางเดียวสม่ำเสมอ, ด่าน 2 กลับทิศไป-มาจริง,
  ด่าน 3 เร็วกว่าด่าน 1 และมีช่วงเร่งแรงกว่าความเร็วปกติราว 2.8 เท่า
- **หน้าวิธีเล่นเข้าธีมร้านเบเกอรี่**: ภาพสาธิตหน้า 2 เป็นชามเซรามิกสีครีม + สายพานไม้ + การ์ดวัตถุดิบสีกระดาษคราฟท์
  (เดิมชามฟ้า/การ์ดชมพู), หน้า 3 แถบเข็ม/ปุ่มสีคาราเมล — ข้อความและลำดับหน้าเหมือนเดิม
- จอแนวนอนเตี้ย: คำพูดของเพื่อนตัวเล็กลง ไม่บังหม้อ/ชาม ; แก้คำพูด "ช่วยด้วยคน!" → "ช่วยอีกแรง!" (เดิมอ่านแล้วเหมือนขอความช่วยเหลือ)
- **ทดสอบอัตโนมัติ 108 รายการ ผ่านทั้งหมด ไม่มี error** (เพิ่ม: ปัดแล้วร่วงลงพื้นจริง ไม่ลอยขึ้น/ไม่ถูกรับไว้,
  ลากนิ้วกวาดจากผนังผ่านของที่กำลังหล่นตามธรรมชาติ, ข้อความเพื่อนใช้คำว่า "ปัด" ไม่ใช่ "รับ", ลูกเล่นสายพาน 3 ด่านตามเวลาจริง)

## รุ่นที่ 14: สายพานอยู่บนจอทุกขั้น + ลูกเล่นต่างกันทั้ง 3 ด่าน + ของแปลกปลอมต้องปัดตก
- **ชั้นวางเป็นสายพานอยู่บนจอทุกขั้น ทั้ง 3 ด่าน** — เดิมชั้นโผล่เฉพาะขั้นหยิบของ (ด่าน 2 เริ่มด้วยขั้นแตะ จึงไม่เห็นชั้นเลย)
  - ขั้นหยิบของ: วัตถุดิบ + ของหลอกวิ่งบนสายพาน ; ขั้นอื่น: **ตู้โชว์ขนม** (ครัวซองต์ โดนัท บาแก็ต ... มีป้ายราคา) เลื่อนผ่าน
    แตะขนมแล้วเด้งดึ๋ง ลากเลื่อนได้เหมือนกัน ; ชั้นไม่หาย-โผล่ระหว่างขั้น ฉากไม่กระตุก
- **ลูกเล่นสายพานแต่ละด่าน** (`Conveyor.trick`)
  - ด่าน 1 คาราเมลคัสตาร์ด: วิ่งนิ่ม ๆ ทางเดียว
  - ด่าน 2 คัพเค้ก: **กลับทิศเป็นระยะ** ป้าย "🔄 สายพานกลับทิศ!"
  - ด่าน 3 คุกกี้: **เร่งความเร็วเป็นช่วง ๆ** ป้าย "⚡ สายพานเร่งความเร็ว!"
  - เปลี่ยนความเร็ว/ทิศแบบนุ่ม ๆ ไม่กระชาก ; ด่านฝึกไม่มีลูกเล่น ; เพื่อน ๆ โยนของช่วยตอนสายพานเปลี่ยน
- **ของแปลกปลอมห้ามรับไว้ ต้องปัดตก**: แตะโดน → กระเด็นออกข้าง หมุนติ้วร่วงลงพื้น (ไม่ลงหม้อ/ชาม) วงประหายทันที ;
  โหมดง่าย/ด่านฝึก เพื่อนกระโดด **ปัดตกพื้น** ให้บ้าง ; ข้อความเตือน "ห้ามให้ตกใส่ขนม แตะปัดทิ้งเลย 👋"
- **ปัด = แตะ หรือลากนิ้วกวาดผ่าน** ของที่หล่นก็ได้ (ระหว่างคน/ร่อน/ลากของ นิ้วกวาดโดนก็ปัดตกพื้น) — `Pests.watchSwipe`
- **เพื่อน ๆ พูดสั้น ๆ เหนือหัวทุกขั้น** (`Helpers.say`, คีย์ `hs.*` ใน i18n.js ไทย/อังกฤษ): เริ่มขั้นบอกว่าทำอะไร
  ("ส่งให้นะ!", "คนเลย ๆ!", "ร่อนแป้งกัน!", "แตะเลย!", "รอเข็มเขียวนะ"), **"กดเลย!" ตอนเข็มเข้าโซนเขียว**, "ปัดตก!" ตอนปัด,
  "สุดยอด!" ตอนสำเร็จ, "โอ๊ะ!" ตอนพลาด, "กลับทิศแล้ว!/เร็วขึ้นแล้ว!" ตอนสายพานเปลี่ยน ; ปิด "คำพูดเชฟ" ในตั้งค่า = เพื่อนเงียบด้วย
- **ทดสอบอัตโนมัติ 102 รายการ ผ่านทั้งหมด ไม่มี error** (เพิ่ม: ลากนิ้วผ่านแล้วปัดตก, เพื่อนบอกขั้น, "กดเลย!" ตอนเข็มเขียว, ชั้นอยู่บนจอขั้นแรกทุกด่าน, ตู้โชว์ด่าน 2, แตะขนมเด้ง,
  ชั้นไม่หายระหว่างขั้น, ด่าน 2 กลับทิศ, ด่าน 3 เร่ง+ป้าย, ด่าน 1 นิ่ม, ปัดแล้วร่วงลงพื้น, ออกจากครัวแล้วชั้นว่าง)

## รุ่นที่ 13: สายพานวัตถุดิบลากได้ + ของแปลกปลอมหล่นจากเพดาน + เพื่อนช่วยปัด
- **ชั้นวัตถุดิบเป็นสายพานวนจริง ทั้ง 3 ด่าน** (`Conveyor` ใน `js/pests.js`): ของวิ่งไปทางขวาเรื่อย ๆ พ้นขอบขวาแล้วโผล่จากขอบซ้าย
  มีลูกกลิ้งไม้ 2 ข้าง ; ด่าน 1 ช้า → ด่าน 3 เร็ว (ปรับตามความยาก, เปลี่ยนความยากกลางเกมก็เปลี่ยนตาม)
  - **ลากชั้นซ้าย-ขวาเองได้** (นิ้ว/เมาส์/ล้อเมาส์) — ลากแนวนอน = เลื่อนสายพาน, ลากขึ้นไปที่ฉาก = หยิบของ, แตะ = ใส่เลย
  - แตะชั้นแล้วหยุดรอให้หยิบ ; ไฮไลต์ตัวที่ถูก → สายพานพาตัวนั้นมากลางชั้น ; ด่านฝึกวางตัวที่ถูกไว้กลางชั้นให้มือ 👆 ชี้ตรง
  - โหมดลดการเคลื่อนไหว: สายพานไม่วิ่งเอง (ลากเองได้) ; เบราว์เซอร์เก่ามาก → ชั้นแบบเดิม เล่นได้ปกติ
- **ของแปลกปลอมหล่นจากเพดาน** 🦟🐜🐛🍂🦗🕸️ ส่ายซ้าย-ขวาลงหม้อ/ชาม (ใบไม้/ใยแมงมุมหมุนคว้าง) — แตะปัดก่อนตกใส่ขนม
  ตกลงไป = เสียหัวใจ 1 ดวง (ด่านฝึกไม่เสีย) ; โหมดลดการเคลื่อนไหว = หล่นตรง ๆ ไม่ส่าย
- **เพื่อน ๆ มีส่วนช่วยทำขนมมากขึ้น**: โหมดง่าย (และด่านฝึก) เพื่อนกระโดดปัดของแปลกปลอมให้บ้าง,
  ตอนช่วยใส่ของ/คน/ร่อน/แต่งหน้า จะโยนอุปกรณ์ที่ถืออยู่เข้าไปทางหม้อ/ชาม
- **คำอธิบายเกม/สอนเล่นเหมือนเดิม** (3 หน้า + สอนในด่านแรก) แค่เพิ่มคำว่า "สายพาน" และ "ของที่หล่นลงมา"
- **แก้บัค**
  - เปลี่ยนเชฟในตั้งค่ากลางเกม → เพื่อนข้างเตาเปลี่ยนตาม (เดิมอาจซ้ำกับเชฟ)
  - เปิดหน้าต่างตั้งค่า/สมุดสูตรตอนอบ → เสียงฉ่า ๆ หยุดด้วย (เดิมเข็มหยุดแต่เสียงยังดัง)
  - หมุนจอ/เปลี่ยนความกว้างจอตอนของกำลังหล่น → ของที่หล่นอยู่จางหายไป ไม่เสียหัวใจ (เดิมจะเล็งไปตำแหน่งหม้อเก่า)
  - ตัวที่ลากตามนิ้วไม่ติดตำแหน่งสายพานมาด้วย
- **ทดสอบอัตโนมัติ 88 รายการ ผ่านทั้งหมด ไม่มี error** (เพิ่ม: ลากสายพานไม่หยิบของ, สายพานตามนิ้ว, ลากขึ้นหยิบ+ใส่ได้,
  ของวนรอบสายพาน, ของหล่นจากด้านบน, เพื่อนช่วยปัดไม่เสียหัวใจ, เปลี่ยนเชฟกลางเกม)

## รุ่นที่ 12: ครัวในเกมเป็นร้านเบเกอรี่ + แมลงก่อกวน + เพื่อนช่วยทำขนม + ชั้นวัตถุดิบเลื่อนได้
- **การ์ดเมนูเริ่มเกมได้เฉพาะปุ่ม "▶ เริ่มทำเลย!"** ทั้ง 3 ใบ — แตะส่วนอื่นของการ์ด/เลื่อนรายการไม่เริ่มเกมโดยไม่ตั้งใจ
- **ห้องครัวในเกม = ร้านเบเกอรี่** (`css/game.css`): ผนังกระเบื้องครีม + แสงโคมไฟอุ่น ๆ, กันสาดลายทางขอบหยัก (สีตามเมนู),
  เคาน์เตอร์ไม้, หน้าต่างกรอบไม้ + ผ้าม่าน, ชั้นไม้บนผนัง, โคมไฟทองเหลือง, ป้ายไม้ชื่อร้าน, ถาดวัตถุดิบไม้, แผงล่างสีครีม/คาราเมล ;
  อุปกรณ์ในฉาก (`js/stage.js`) เปลี่ยนเป็นหม้อทองแดง เตาเหล็ก ชามเซรามิกครีม เขียงไม้ ถาดอบโลหะ ถ้วยกระดาษคราฟท์ เตาอบ/ตู้เย็นสีครีม
- **ท้าทายขึ้น: แมลงก่อกวน 🦟🐜🐞🍂** (`js/pests.js` → `Pests`) บินส่ายไปมาเข้าหาหม้อ/ชาม — **แตะเพื่อปัดออก**
  - ถ้าตกลงไปในขนม = เสียหัวใจ 1 ดวง (ด่านฝึกไม่เสีย) ; ด่าน 1 มาห่าง ๆ บินช้า → ด่าน 3 มาบ่อย บินเร็ว มาได้ทีละ 2 ตัว (ปรับตามความยากด้วย)
  - พักเองตอนเปิดหน้าต่าง/สลับแอป/ไฟส่องสอนเล่น ; ตอนจับเวลาเตาอบมาห่างขึ้น ; ปิดได้ที่ ⚙️ → 🦟 แมลงก่อกวน
  - บินด้วย Web Animations (การ์ดจอทำให้) + นาฬิกาสำรองของเกม แมลงไม่ค้างกลางอากาศแม้เครื่องหยุดวาดเฟรม
- **เพื่อน ๆ ช่วยทำขนมทุกด่าน** (`Helpers`): ตัวละคร 2 ตัวที่ไม่ได้เลือกเป็นเชฟยืนข้างเตา ถืออุปกรณ์ตามขั้น
  (🧺 ตะกร้าวัตถุดิบ / 🥄 ทัพพี / 🌾 แป้ง / 🍓 แต่งหน้า / 🧤 ถุงมือเตาอบ+⏲️) — กระโดดปัดแมลง, ช่วยรับของใส่หม้อ,
  ช่วยคน/ร่อน/แต่งหน้า, เชียร์ตอนทำสำเร็จ 🎉, ตกใจตอนพลาด 💦
- **ชั้นวัตถุดิบเลื่อนได้แบบสายพาน** (`Conveyor`): ของเรียงแถวเดียว เลื่อนไป-มาเองช้า ๆ (ด่านยากเลื่อนเร็วขึ้น),
  ใช้นิ้วปัดซ้าย-ขวาเลื่อนเองได้ (เมาส์ใช้ล้อหมุน), แตะ/ปัดแล้วหยุดรอให้หยิบ, ลากขึ้นไปที่ฉาก = หยิบของ,
  ไฮไลต์ตัวที่ถูกแล้วชั้นเลื่อนพามาให้เห็น ; ของบนชั้นขยับดุ๊กดิ๊กเบา ๆ
- **ประสิทธิภาพ**: ทุกอย่างที่ขยับใช้ transform/translate/opacity เท่านั้น, วัดขนาดชั้นแค่ครึ่งวินาทีครั้ง, ตัวจับเวลาแมลง/ชั้นหยุดทันทีเมื่อออกจากครัว,
  โหมดเบาปิดท่าขยับตกแต่งของเพื่อน ๆ และของบนชั้น
- **ทดสอบอัตโนมัติ 78 รายการ ผ่านทั้งหมด ไม่มี error** (เพิ่ม: กดได้เฉพาะปุ่มเริ่ม, เพื่อน 2 ตัวทุกด่าน, ชั้นเลื่อนเอง,
  แมลงตก = เสียหัวใจ, ปัดแมลง = ไม่เสีย, ด่านฝึกไม่เสีย, ปิดแมลงได้, ไม่มีแมลง/ตัวจับเวลาค้างหลังออกจากครัว)

## รุ่นที่ 11: สอนเล่นแค่ด่านแรก + ห้องครัวเบเกอรี่ + ตั้งค่าใหม่ + เสถียร/ลื่นขึ้น
- **สอนเล่นสั้น ๆ เข้าใจง่าย**
  - หน้าแนะนำเหลือ 3 หน้า: ยินดีต้อนรับ → ทำตามเชฟ (แตะ/ลาก/ถู) → กดตอนเข็มเขียว + หัวใจ
  - สอนในด่านเฉพาะ **ด่านแรก (คาราเมลคัสตาร์ด) ตอนเล่นครั้งแรก** — ด่าน 2 และ 3 ไม่สอน
  - ป้ายในด่านสั้นลงเหลือคำเดียว เช่น "แตะ น้ำตาลทราย, น้ำเปล่า 👆", "ถูนิ้ววน ๆ บนชาม 🌀", "กดเลย! 👆"
  - เอามือสาธิต "ครั้งแรกของแต่ละท่า" ในด่านอื่นออก (ด่านอื่นไม่สอน)
- **หน้าเลือกเมนู = ห้องครัวเบเกอรี่ขนาดใหญ่** (`css/shop.css` + `js/shop.js`): ผนังกระเบื้องครีม, ราวแขวนกระทะ/ช้อน,
  ชั้นโหลแป้งและขนมปัง, **เตาอบอิฐโค้งใหญ่มีไฟ**, ชั้นตะแกรงขนมปังสูง, โต๊ะทำขนมไม้ยาว,
  **เพื่อน ๆ ตัวเล็กยืนทำขนมหลังโต๊ะ** (ตัวเล็กกว่าเตา/ชั้นวาง) ; เชฟมุมขวาล่างเล็กลง ; ป้ายร้านไม้ห้อยโซ่
- **หน้าแรกน้ำตาลอ่อนลง**: อิฐโทนขนมปังอบสีอ่อน แสงสว่างขึ้น พื้น/เคาน์เตอร์อ่อนลง ป้ายร้านไม้สีเข้มเด่นขึ้น
- **หน้าตั้งค่าแบบร้านเบเกอรี่** (`css/ui.css`): การ์ดกระดาษครีมขอบคาราเมล หัวลายกันสาด,
  แบ่งหมวด 🎮 การเล่น / 🔊 เสียง / ✨ ตัวช่วย / 🧑‍🍳 เชฟของฉัน, ปุ่มเลือก/สวิตช์/แถบเลื่อนสีคาราเมล ปุ่มใหญ่กดง่าย,
  ชื่อตัวเลือกสั้นลง ; หน้าสมุดสูตรใช้สไตล์เดียวกัน ; วงโฟกัสคีย์บอร์ดเป็นสีคาราเมล
- **ลื่นขึ้น ไม่กระตุก**
  - **โหมดเบาอัตโนมัติ** สำหรับเครื่องสเปกต่ำ (CPU ≤4 คอร์ หรือ RAM ≤3 GB): ปิดแอนิเมชันตกแต่งที่วนตลอดเวลา, ขนมร่วงเหลือ 5 ชิ้น
  - แต่ละหน้าแยกการคำนวณเลย์เอาต์/วาดออกจากกัน (`contain`), ตัวอักษรโลโก้ที่มีเงาหลายชั้นวาดครั้งเดียว (`will-change`)
  - ไฟส่องในด่านฝึกไม่ทำแอนิเมชันขนาด/ตำแหน่ง (เดิมต้องวาดเงาทั้งจอใหม่ทุกเฟรม) และไม่วาดเลยตอนซ่อน
- **ทดสอบอัตโนมัติ 57 รายการ ผ่านทั้งหมด ไม่มี error**: เล่นจบครบ 3 เมนู × 3 ระดับ × 2 ภาษา, สอนเล่นเฉพาะด่านแรก,
  แพ้ (ไหม้/ไม่สุก/หัวใจหมด) + เริ่มใหม่, ปุ่มย้อนกลับ, เปลี่ยนภาษา/ความยาก/ลดการเคลื่อนไหวกลางเกม,
  กดปุ่มรัว ๆ ไม่ข้ามขั้น, เข้า-ออกเกมสุ่ม 25 รอบไม่ค้าง ไม่มีของค้างบนจอ

## รุ่นที่ 10: แพ้แล้วเริ่มใหม่ + การ์ด/รูปขนมแบบร้านเบเกอรี่
- **อบไหม้หรือทำผิด = แพ้ ต้องเริ่มเมนูใหม่** (`G.fail` / `G.miss` ใน `js/engine.js`)
  - จับเวลา: กดช้าจนเลยโซนเขียว หรือปล่อยให้เข็มวิ่งสุด = **ขนมไหม้** (สีดำเกรียม + ควัน 💨) → แพ้
  - กดก่อนโซน = **ไม่สุก** → แพ้ (โหมดง่าย: กดก่อนโซนแค่เตือน ไม่นับ ; แตะภาพก่อนโซนก็แค่เตือน กันแตะโดนแล้วแพ้)
  - **หัวใจ ❤️** มุมซ้ายบนของครัว (ง่าย/ปกติ 3 ดวง, ท้าทาย 2 ดวง): ใส่วัตถุดิบผิด / คนแรงเกิน = เสีย 1 ดวง หมด = แพ้
  - หน้าแพ้: รูปขนมเมนูนั้นแบบไหม้/ซีด + บอกสาเหตุ + ปุ่ม "🔁 เริ่มใหม่" (เริ่มขั้นแรก หัวใจเต็ม) และ "🍰 เลือกเมนูอื่น"
  - โหมดสอนเล่น: ไม่แพ้ ไม่เสียหัวใจ — ถ้าไหม้/ไม่สุก จะให้ลองขั้นนั้นใหม่ทันที
- **รูปขนมการ์ตูนแบบร้านเบเกอรี่** (`js/icons.js`, ยังน่ารักมีหน้าตาเหมือนเดิม):
  คาราเมลคัสตาร์ดบนกระดาษรองลูกไม้ (doily) + จานครีม + ซอสคาราเมลเข้ม + วิปครีม + เชอร์รี,
  คัพเค้กถ้วยกระดาษคราฟต์สีน้ำตาล + บัตเตอร์ครีมวานิลลาราดคาราเมล, คุกกี้ตัวร้ายเขาช็อกโกแลต + ช็อกชิปเข้ม บนกระดาษไข
- หน้าเลือกเมนูใช้ฉากหลังเดิม (คาเฟ่ครีม ไฟประดับ ป้ายนีออน) ตามที่ขอ ; ลายอิฐย้ายไปเป็นตัวแปร `--brick` ใน `base.css`
- **การ์ดเมนูเป็นเบเกอรี่ขึ้นอีก**: ขนมวางบน **ขาตั้งเค้กใต้ครอบแก้ว** ในตู้โชว์กรอบไม้, **ชื่อเมนูบนริบบิ้น**,
  **ป้ายราคาห้อยเชือก** (คัสตาร์ด ฿35 · คัพเค้ก ฿45 · คุกกี้ ฿25 — แก้ได้ที่ `price` ใน `recipes.js`) ; คอมชี้เมาส์ = ยกครอบแก้วขึ้น

## รุ่นที่ 9: โหมดสอนเล่นในด่านแรก ๆ + การ์ดเมนูแบบร้านเบเกอรี่
- **โหมดสอนเล่น 🎓** (`Tutor` ใน `js/howto.js`): ครั้งแรกที่เล่นแต่ละเมนู (เมนูที่ยังไม่เคยทำจบ)
  - ทุกขั้น: หรี่ไฟทั้งจอ ส่องไฟตรงจุดที่ต้องเล่น (ชั้นวัตถุดิบ / ชาม / มิเตอร์ / ปุ่ม) + ป้ายบอกชัด ๆ เช่น
    "แตะ น้ำตาลทราย, น้ำเปล่า ให้ครบ" + มือ 👆 สาธิต ; แตะครั้งแรกไฟส่องหายไป เล่นต่อเองได้เลย
  - จับเวลา: ช่วงแรกส่องที่มิเตอร์ "รอให้เข็มเข้าโซนเขียวก่อน…" → เข็มเข้าโซน ส่องที่ปุ่ม "ตอนนี้แหละ! กดเลย"
  - ระหว่างฝึก: หยิบผิดไม่เสียดาว, ไฮไลต์วัตถุดิบที่ถูกเกือบทันที, เข็มจับเวลาช้าลง 20%
  - ป้าย "🎓 โหมดสอนเล่น" มุมซ้ายบนของครัว, จบเมนูแล้วหน้าสรุปผลขึ้น "ผ่านด่านฝึกแล้ว!" ; เล่นซ้ำครั้งต่อไปเป็นโหมดปกติ
  - ปิด/เปิดได้ที่ ⚙️ ตั้งค่า → "🎓 สอนเล่นในด่าน" (อยากฝึกใหม่: ล้างคะแนนดาว)
- **การ์ดเมนูแบบร้านเบเกอรี่** (`css/menu.css`): กระดาษคราฟต์มีรอยเย็บ, กันสาดลายทางสีประจำเมนูบนหัวการ์ด,
  ขนมวางบนจานลูกไม้บนชั้นไม้ในตู้โชว์, ป้ายห้อยแบบป้ายราคา, เลขเมนูเป็นตราประทับช็อกโกแลต, ปุ่มสีคาราเมล
  - สีประจำเมนู: คัสตาร์ด = คาราเมล, คัพเค้ก = สตรอว์เบอร์รี, คุกกี้ = ช็อกโกแลต (แก้ได้ที่ `.card[data-id=...]`)
  - เอาแสงหมุนในรูปการ์ดออก (ภาพนิ่ง ประหยัดแบต)

## รุ่นที่ 8: แนะนำเกม + สอนเล่น
- **หน้าแนะนำเกม/สอนเล่น 7 หน้า** (`js/howto.js` + `css/howto.css`) ขึ้นเองครั้งแรกที่กด "เริ่มเกม" แล้วค่อยไปหน้าเลือกเมนู
  1. ยินดีต้อนรับ (เชฟ + ขนม 3 เมนู) 2. ใส่วัตถุดิบ 3. คน/ตี 4. ร่อน/กรอง 5. แตะ 6. จับเวลา 7. ดาวและปุ่มช่วย
  - ทุกหน้ามีภาพเคลื่อนไหวสาธิตท่าเล่น (มือ 👆 หยิบไข่ใส่ชาม, วนนิ้วบนชาม, เขย่ากระชอน, แตะถ้วยที่กระพริบ, กดตอนเข็มเข้าโซนเขียว)
  - เปลี่ยนหน้าได้ทั้งปุ่ม "ถัดไป", แตะจุด, ปัดซ้าย-ขวา, ปุ่มลูกศร; กด "ข้าม" ได้ทุกเมื่อ
  - ดูอีกครั้งได้ที่ ⚙️ ตั้งค่า → ❓ วิธีเล่น → "ดูอีกครั้ง" ; รองรับไทย/อังกฤษ
- **มือ 👆 สาธิตบนฉากจริงในครัว** ครั้งแรกที่เจอวิธีเล่นแต่ละแบบ (ใส่วัตถุดิบ / คน / ร่อน / แตะ / จับเวลา)
  - หายเองใน 4 วินาที หรือทันทีที่ผู้เล่นแตะ ; ปิดได้ด้วย "ไฮไลต์ตัวช่วย" หรือ "ลดการเคลื่อนไหว"
  - กด "ดูอีกครั้ง" ในหน้าตั้งค่า มือสาธิตจะกลับมาอีกรอบด้วย

## รุ่นที่ 7: ภาษาอังกฤษ + ขนมร่วง + หัวใจ
- **สลับภาษา ไทย / English ได้ทั้งเกม** (`js/i18n.js` + `js/recipes-en.js`):
  - เลือกได้ที่หน้าตั้งค่า ⚙️ แถวบนสุด "🌐 ภาษา / Language" (จำค่าไว้ เปิดครั้งหน้ายังเป็นภาษาเดิม)
  - แปลครบ: ปุ่ม เมนู การ์ด คำสั่งในครัว คำพูดเชฟ/เพื่อน ๆ เคล็ดลับ วัตถุดิบ สมุดสูตร หน้าสรุปผล หน้าตั้งค่า และป้ายสำหรับโปรแกรมอ่านหน้าจอ
  - สลับกลางเกมได้ ข้อความในครัวเปลี่ยนทันที ไม่ต้องเริ่มใหม่
  - ค่าเริ่มต้นเป็นภาษาไทย; ถ้าลืมแปลข้อความไหน เกมจะใช้ภาษาไทยแทน ไม่พัง
- **ขนมร่วงลงมาช้า ๆ** บนหน้าแรก (เป็นฉากหลังเฉย ๆ แตะไม่ได้ ไม่บังปุ่ม) ร่วงจากใต้กันสาด ผ่านหลังป้ายร้านและเพื่อน ๆ
  - สร้างครั้งเดียวแล้ววนด้วย CSS (ไม่สร้าง/ลบของใหม่ตลอดเวลา) ขยับแค่ transform จึงไม่กระตุก
  - เปิด "ลดการเคลื่อนไหว" จะไม่มีขนมร่วง
- **แตะชื่อร้าน = หัวใจลอยขึ้น** 💖💕💗 จากจุดที่แตะ (แตะตรงไหนของป้ายก็ได้) + ตัวอักษรที่แตะเด้ง; แตะคุกกี้ยังกรุบเหมือนเดิม

## รุ่นที่ 6: หน้าแรกเป็นร้านเบเกอรี่โทนน้ำตาล + ลื่นขึ้น เล่นง่ายขึ้น
- **หน้าเริ่มเกม = ในร้านขนมปังโทนน้ำตาล** (`css/start.css` + `css/logo.css`, CSS ล้วน ไม่มีรูปเพิ่ม):
  ผนังอิฐโทนน้ำตาล + แสงไฟอุ่นหลังป้ายร้าน, **โลโก้อยู่บนป้ายร้านไม้ติดน็อตทองเหลือง** (ริบบิ้นพาดขอบล่าง),
  กันสาดลายน้ำตาล-ครีม, โคมไฟห้อยเพดาน, ชั้นวางขนมปังเหนือป้าย + ชั้นวางเค้ก/คุกกี้ใต้ปุ่มเริ่มเกม,
  **ตู้กระจกโชว์ขนมติดป้ายราคา** บนเคาน์เตอร์ไม้ + ขนมปังเพิ่งอบมีไอร้อน, พื้นกระเบื้องตารางน้ำตาล, ฝุ่นแป้งระยิบระยับ
  - ชั้นวางโชว์เฉพาะตอนจอมีที่ว่างพอ (container query) จึงไม่ทับโลโก้/ปุ่ม/ตัวละครในจอไหนเลย
  - แถบสถานะมือถือเปลี่ยนสีตามหน้า (น้ำตาลที่หน้าแรก ครีมที่หน้าเมนู)
- **เอาของที่ตก/ลอยออกทั้งหมด:** ขนมตกลงมาให้แตะเก็บ + ข้อความ "แตะขนมที่ตกลงมาเพื่อเก็บ…", ฟองสบู่, ลูกโป่ง, ดอกไม้,
  ฝนขนมหน้าเมนู, อีโมจิลอยขึ้นในห้องครัว, กระดาษสีร่วงหน้าสรุปผล, ประกายตอนแตะพื้นที่ว่าง
- **ลื่นขึ้น:**
  - ฉากทำอาหารแก้เฉพาะจุดที่เปลี่ยน (ไม่สร้างภาพใหม่ทั้งก้อนทุกเฟรมตอนคน/ร่อน/อบ) แอนิเมชันไฟ/ไอน้ำไม่สะดุด
  - เข็มจับเวลา + แสงวาบบนปุ่มเลื่อนด้วย transform (การ์ดจอทำให้), ลากวัตถุดิบขยับครั้งเดียวต่อเฟรม
  - อ่านขนาดฉากครั้งเดียวตอนแตะ ไม่บังคับคำนวณเลย์เอาต์ทุกครั้งที่นิ้วขยับ, รวมการอัปเดตความสูงจอเป็นครั้งเดียวต่อเฟรม
  - ฉากหลังหน้าแรกเป็นภาพนิ่งเกือบทั้งหมด (ไม่มีแสงหมุน/ก้อนเมฆ/ลูกโป่งวิ่งตลอดเวลา) ประหยัดแบต
- **เล่นง่ายขึ้น:**
  - ขั้น "แตะ" กระพริบเฉพาะชิ้นที่ต้องแตะต่อไป (เดิมกระพริบทุกชิ้น แม้ตอนไม่ต้องแตะ)
  - ปุ่มจับเวลานับตั้งแต่นิ้วแตะปุ่ม ไม่ต้องรอยกนิ้ว → ตรงจังหวะกว่าเดิม
  - วางวัตถุดิบใกล้ ๆ ฉากก็นับ (จอสัมผัสขยายระยะเป็น 64px)
  - โหมดง่าย: คน/ตีน้อยลง (รอบ ×0.5, แตะรัว 8 ครั้งก็ครบ), โหมดปกติ: รอบ ×0.8 / แตะ 12 ครั้ง
- **เสถียรขึ้น:** ปุ่มย้อนกลับของมือถือ (Android) / ปัดย้อนกลับ (iPhone) ถอยทีละหน้าในเกม
  (หน้าต่าง → ครัว → เมนู → หน้าแรก) ไม่หลุดออกจากเกมกลางคัน

## รุ่นที่ 5: โทนร้านขนมปัง
- **โลโก้โทนน้ำตาลอ่อน** (`css/logo.css`): เลิกใช้สีรุ้ง/สี RGB ทั้งหมด
  - ใช้ฟอนต์ตกแต่งเฉพาะคำว่า **Deejat** (ฟอนต์ตัวอ้วนกลมเหมือนเบเกิล) สีน้ำตาลอ่อนเหมือนขนมปังอบ ขอบครีม เงาน้ำตาล และเงาวาวด้านบน
  - **BAKERY** เป็นตัวพิมพ์ใหญ่ธรรมดา เว้นระยะห่าง มีเส้นขีดสองข้างแบบป้ายร้านขนมปัง
  - ริบบิ้นสีคาราเมล "fresh baked daily · since 2000", ปุ่มเริ่มเกมสีคาราเมล
- **หน้าเริ่มเกมโทนครีม-น้ำตาลอ่อน**: กันสาดลายน้ำตาล-ครีม, ท้องฟ้าครีม, ส่วนโค้งสีขนมอบแทนรุ้งสีสด
- **ฉากหลังหน้าเลือกเมนู = คาเฟ่เบเกอรี่ของวัยรุ่น** (`css/shop.css` + `js/shop.js`, วาดด้วยโค้ด ไม่มีรูปเพิ่ม):
  - ป้ายนีออน "Deejat Bakery" และป้ายนีออน "open ♡"
  - ไฟประดับห้อยเป็นโค้ง, รูปโพลารอยด์ติดเทปวาชิ, สติกเกอร์หน้ายิ้ม/หัวใจ/ดาว
  - ผนังครีมลายจุด + ไม้ระแนง, พื้นตารางหมากรุกครีม-ลาเต้, ชั้นวางขนมปังกับต้นไม้, กระดานชอล์ก "today's bake", เคาน์เตอร์ไม้ + ตู้กระจกขนมปัง
  - บนมือถือแนวตั้งจะเหลือของแต่งที่โผล่ตามขอบจอ ไม่บังการ์ด
- **ฟอนต์เก็บไว้ในเกม** (`css/fonts.css` + `assets/fonts/`): ไม่ต้องโหลดจาก Google Fonts แล้ว
  - เล่นได้แม้ไม่มีเน็ต และหน้าตาเหมือนกันทุกเครื่อง
  - เบราว์เซอร์ในแอป (เช่น Facebook / LINE) ที่บล็อก Google Fonts ก็ยังได้ฟอนต์ครบ
  - `build.py` ฝังฟอนต์เข้าไฟล์เดียวให้อัตโนมัติ (รวมประมาณ 100 KB)
- ทดสอบแล้ว 13 ขนาดจอ (320×568, Z Fold จอนอก 344×882, Z Flip จอนอก 360×374, 360×780, 375×667, 390×844, 412×915, 430×932, แนวนอน 667×375 / 844×390, จอพับกางออก 673×841, แท็บเล็ต 820×1180, คอม 1280×800): ไม่ล้นจอ ไม่มี error และเล่นจบครบทั้ง 3 เมนู

## รุ่นที่ 4: เปลี่ยนชื่อเป็น DeejatBakery
- เปลี่ยนชื่อเกมเป็น DeejatBakery (คุกกี้ย้ายไปติดตัว t แตะแล้วยังกรุบเหมือนเดิม, แตะตัวอักษรแล้วเด้ง)

  - ส่วนต่าง ๆ ตอนเปิดเกมเริ่มแยกกัน ถ้าของตกแต่งพัง ปุ่มและตัวเกมยังใช้ได้
  - จับ error และ Promise ที่หลุดทั้งหมด (ดูได้ที่ `DeejatBakery.Safe.log` ในคอนโซล)

  - `build.py` สร้างไฟล์เหมือนกันทุกเครื่อง และหยุดถ้าโค้ดมี `</script` ที่จะทำให้ไฟล์เดียวพัง

## วิธีเล่น / เปิดเกม

- **ไฟล์เดียวพร้อมเล่น:** `dist/DeejatBakery.html` — ส่งเข้ามือถือแล้วเปิดด้วย Safari / Chrome ได้เลย
- **แบบแยกไฟล์ (สำหรับแก้โค้ด):** เปิด `index.html` (ต้องอยู่คู่กับโฟลเดอร์ `css/` และ `js/`)

## สิ่งที่แก้และปรับปรุง

### รองรับมือถือทุกรุ่น
- **แก้บั๊กใหญ่:** เดิมห้องครัวสูงเต็มจอ ทำให้แผงด้านล่าง (คำสั่ง, มิเตอร์, ปุ่ม "เอาออกจากเตา!") ถูกดันตกขอบจอ ในหลายรุ่นกดปุ่มจับเวลาไม่ได้เลย
- พื้นที่ทำอาหารคำนวณขนาดเองให้ใหญ่ที่สุดเท่าที่จอว่าง (ทดสอบที่ 320×568 ถึง 820×1180 และแนวนอน 844×390)
- รองรับรอยบาก / Dynamic Island / แถบ Home ของ iPhone และแถบนำทางของ Android (safe area)
- แก้ปัญหา `100vh` ที่แถบเบราว์เซอร์มือถือยุบ-ขยายแล้วจอเลื่อน
- หมุนจอแนวนอน: ห้องครัวอยู่ซ้าย แผงคำบรรยายอยู่ขวา
- ชั้นวัตถุดิบจัด 4 ช่องต่อแถวบนมือถือ ไม่ล้นจอ
- ยกเลิก CSS ซ้อนทับกันหลายชุดที่เคยตีกันเอง รวมเป็นชุดเดียวที่อ่านง่าย
- เลื่อนการ์ดเมนูด้วยนิ้วได้ปกติ (เดิมปุ่มบล็อกการเลื่อน)
- กันจอเด้ง, กันซูมด้วยสองนิ้ว, กันเมนูค้างกดของ iPhone ขณะเล่น

### เล่นง่ายขึ้น (ค่าเริ่มต้น "ง่ายมาก" ปรับได้ในตั้งค่า)
- **ใส่วัตถุดิบ:** แตะเฉย ๆ ก็ใส่ได้ ลากไปใกล้ ๆ ก็นับ, วัตถุดิบหลอกเหลือ 1 ชิ้น, หยิบผิดจะขึ้นกากบาทไม่ต้องกดซ้ำ, รอสักครู่จะไฮไลต์ตัวที่ถูกให้
- **คน/ตี:** ถูนิ้ววน ๆ หรือถูไปมาก็นับ ไม่ต้องวนเป็นวงกลมเป๊ะ, รอบน้อยลง, แตะรัว ๆ ก็ได้
- **ร่อน/กรอง:** ระยะที่ต้องถูปรับตามขนาดจอ, จำนวนครั้งน้อยลง
- **แตะ:** แตะตรงไหนบนฉากก็ได้ เกมเลือกถ้วยถัดไปให้เอง
- **จับเวลา:** เข็มวิ่งเร็วช่วงแรก (ไม่ต้องรอนาน), โซนเขียวกว้างขึ้น, เข็มช้าลงในโซน, ปุ่มเปลี่ยนเป็นสีเขียว + สั่นเตือนตอนถึงเวลา, กดเร็วเกินไปจะยังไม่นับ
- พลาดได้ 2 ครั้งก่อนเสีย 1 ดาว (โหมดง่าย)

### รุ่นที่ 3
- **ตัวละคร:** เชฟแว่นตา (GIF) แทนที่บันนี่ ส่วนมีโอกับหมีหม่ำยังอยู่เหมือนเดิม เลือกตัวละครได้ในตั้งค่า (ค่าเริ่มต้น = เชฟแว่นตา)
- **เชฟแว่นตาขยับได้:** รูป GIF ยุบ-ยืดเองตลอด + โยกตัวเบา ๆ, กระโดดดีใจ ✨ ตอนทำถูก, ส่ายตัว 💦 ตอนหยิบผิด, แตะแล้วกระโดด+พูด, ลากเล่นในหน้าเริ่มได้ (ปล่อยแล้วเด้งกลับ)
- **โลโก้:** เอาหัวใจข้างตัว J ออก ใส่คุกกี้ติดตัว J แทน แตะคุกกี้แล้วมีเสียงกรุบ + เศษคุกกี้กระเด็น
- เสียงและเพลงเดิมครบทุกเสียง (เพิ่มเสียงกรุบคุกกี้ 1 เสียง)
- จอนอกมือถือพับ (Z Flip, Razr) ใช้เลย์เอาต์แนวตั้งแบบกะทัดรัด ชั้นวัตถุดิบเรียงแถวเดียว ไม่บังชาม
- เลย์เอาต์ครัวซ้าย-แผงขวาใช้เฉพาะจอกว้าง ≥560px (มือถือหมุนจอ, จอพับกางออก, แท็บเล็ต)
- หน้าตั้งค่าไม่ตัดคำแปลก ๆ บนจอแคบ
- ในไฟล์เดียว รูปถูกแปลงเป็น blob ครั้งเดียว ทุกตัวใช้รูปเดียวกัน ประหยัดหน่วยความจำ
- ถ้ารูปหาย เกมยังเล่นต่อได้ (ใช้อีโมจิ 👩‍🍳 แทน), เปิด "ลดการเคลื่อนไหว" จะใช้รูปนิ่งแทน GIF
- รองรับมือถือพับโหมด Flex (Viewport Segments), กันเบราว์เซอร์ Samsung / Xiaomi บังคับโหมดมืดจนสีเพี้ยน

### ประสิทธิภาพ
- วาดฉากรวมเป็นครั้งเดียวต่อเฟรม และข้ามการวาดถ้าภาพไม่เปลี่ยน (ไฟ/ไอน้ำ/ฟองเดือดขยับต่อเนื่องได้แล้ว)
- ตอนอบ/เคี่ยว วาดฉากใหม่แค่ 40 ครั้งแทนทุกเฟรม
- ลดจำนวนของตกแต่งบนจอเล็ก, ปิดแอนิเมชันหนัก ๆ บนจอสัมผัส
- พักเพลงเมื่อสลับแอป/ล็อกจอ, ปลดล็อกเสียงแบบที่ iPhone ต้องการ
- ป้องกันเข็มกระโดดหลังกลับมาจากแอปอื่น
- เคารพการตั้งค่า "ลดการเคลื่อนไหว" ของเครื่อง

## เปลี่ยนรูปเชฟแว่นตา
1. แทนที่ `assets/chef.gif` ด้วยรูปใหม่ (พื้นหลังโปร่งใส ตัดขอบว่างออกให้ชิดตัวละคร)
2. แทนที่ `assets/chef-still.png` ด้วยเฟรมนิ่ง 1 เฟรม
3. แก้ `CHEF_W` / `CHEF_H` ใน `js/assets.js` ให้ตรงขนาดรูป
4. รัน `python3 build.py`
